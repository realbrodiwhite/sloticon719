# **App Name**: Sloticon Manager

## Core Features:

- Code Modernization: Merge and modernize the code from GitHub repositories github.com/ktsalik/sloticon and github.com/ktsalik/sloticon-server into a single Next.js project.
- User Management UI: Implement a user interface to manage user accounts within the Sloticon application.
- Secure Access Control: Add authentication to restrict access to the management interface to authorized users only.
- Dashboard Analytics: Visualize key metrics related to user activity within the management interface.

## Style Guidelines:

- Use a monochromatic color scheme with varying shades of gray to create a clean, professional look.
- Use color sparingly for important actions or alerts.
- Accent color: Use Teal (#008080) to add a touch of sophistication to the overall design.
- Employ a grid-based layout to maintain consistent spacing and alignment throughout the application.
- Maintain consistency in font sizes and weights for headings, labels, and body text.
- Utilize a consistent style for icons, such as outline or filled, across the entire application.
